# Public downloads

CSV exports are generated from the final 2026-11-07 data snapshot: 1,211 screening records, 92 full-text reports sought, 83 full-text assessments, and a 61-study synthesis. The OpenAlex archive is provided as a separate ZIP. Source workbooks containing full abstracts and original reviewer notes are not served from this static website.

Missing OpenAlex metadata is not imputed. PDF manuscript images are available in `figures/paper/` and the manuscript itself is provided as `manuscript-v6.pdf`.
